# Wheelchair Park

3D-игра: Three.js + cannon-es (RaycastVehicle) + PeerJS (P2P-мультиплеер). Полностью статическая, Vite.

## Запуск
```bash
npm install
npm run dev        # http://localhost:5173
```

## Управление
T или кнопка — смена скина (Турбо: 1000 л.с., 1500 Н·м) · W/S или ↑/↓ — газ/тормоз/задний ход · A/D или ←/→ — руль · Пробел — олли · Shift — ручник (занос) ·
R — респавн · ЛКМ + мышь — камера · колесо мыши — зум.

## Мультиплеер
Скопируй свой ID, отправь другу; друг вставляет его в поле «ID друга» и жмёт «Подключиться».
Подключение идёт через бесплатный облачный сигнальный сервер PeerJS, дальше — напрямую (WebRTC).
Третий игрок, подключившись к любому из двоих, автоматически соединяется со всеми.

## Деплой на GitHub Pages
Вариант A (Actions, рекомендуется): создай репозиторий, `git push` в ветку `main`,
в Settings → Pages выбери Source: **GitHub Actions**. Workflow уже лежит в `.github/workflows/deploy.yml`.

Вариант B (gh-pages): `npm run deploy`, затем Settings → Pages → Branch: `gh-pages` / root.

## Телефон и полный экран
- На сенсорных устройствах включается экранное управление: ◀ ▶ — руль, ▲ ▼ — газ/тормоз, «Ручник», «Прыжок», «Скин», ↻ — респавн, ☰ — панель с ID для мультиплеера. Камера крутится свайпом по экрану. Принудительно включить его на ПК: `?touch` в адресе.
- Полный экран: F11, кнопка ⛶ или автоматически при первом касании/нажатии клавиши (браузеры не разрешают включать его без действия пользователя). На Android доп. включается альбомная ориентация.
- iPhone/iPad Safari не поддерживает полноэкранный режим для сайтов: открой игру → «Поделиться» → «На экран Домой», и она запустится без адресной строки.

## Звук и опасный склон
- Звук генерируется на лету (WebAudio, без файлов): щелчки и скрип колёс обычной коляски, шорох по асфальту, визг на ручнике, приземления; у «Турбо» — рычащий двигатель с коробкой передач, свист турбины и выстрелы в глушителе при сбросе газа. Клавиша M или кнопка 🔊 — вкл/выкл.
- На карте есть «Опасный склон» (жёлто-чёрные полосы и табличка наверху, юго-восточнее старта по оси Z ≈ +135). На нём нельзя разгоняться быстрее ≈65 км/ч: коляска начинает трястись и дымить (шкала перегрузки), а при превышении разваливается на детали. R — собрать заново (или само через 6 секунд). Другие игроки видят взрыв.
- Лимит скорости меняется константой `SLOPE_LIMIT` в `src/main.js`.

## Бабки
В парке стоят 18 бабок (10 на площади, остальные по карте, не на рампах и не на склоне). Они поворачиваются к тебе, а если въехать — отлетают и говорят голосом браузера (русская озвучка, Web Speech API) «Человек в тележке катиться он здоровый человек?» с пузырём над головой. Через 7 секунд встают на место. Счётчик сбитых — справа сверху. Если в браузере нет русского голоса, будет только пузырь и «ой». Бабки у каждого игрока свои (не синхронизируются по сети).
